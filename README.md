# HProxy for Homebrew

The `hproxy` command on macOS and Linux: check proxies, list free ones, look up IPs, connect through a proxy, and give
AI assistants the same tools as an MCP server (`hproxy mcp`).

```bash
brew install hproxy-com/tap/hproxy
hproxy --help
```

Every version is built in public from source (https://github.com/hproxy-com/proxy-all-in-one-tool/releases) and this formula names the
SHA-256 sums of that release. Upgrade with `brew upgrade hproxy`.
